# 常见问题（示例，替换成你自己的问答）

## 价格怎么算？

按设备数（每个企业微信账号算一台）订阅，含服务端更新与智能体配置协助；
具体金额按沟通情况定，不含税费。

## 需要准备什么？

1. 一台能开机联网的安卓手机（Android 7.0 以上），单独放这个企业微信账号；
2. 一台服务器（2 核 4G 起）；
3. 一个大模型 API Key（OpenAI 兼容接口即可）。

## 会不会封号？

本系统通过无障碍模拟人工操作，属于非官方途径，存在被平台限制的风险。
我们不做对抗检测的处理，也不建议高频群发；请按平台规范使用。

## 消息会不会被第三方看到？

消息只存在你自己的服务器上；只有需要生成回复的批次内容会发给你配置的大模型服务商。
